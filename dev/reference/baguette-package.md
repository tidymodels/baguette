# baguette: Efficient Model Functions for Bagging

Tree- and rule-based models can be bagged
([doi:10.1007/BF00058655](https://doi.org/10.1007/BF00058655) ) using
this package and their predictions equations are stored in an efficient
format to reduce the model objects size and speed.
